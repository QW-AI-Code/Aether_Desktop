# گزارش اصلاح رابط Aether Windows 1.4.0

## نوع بسته و محدودیت مهم
این بسته شامل **سورس کامل اصلاح‌شده و خروجی production فرانت‌اند در `dist-web`** است؛ نصب‌کننده یا EXE جدید ویندوز نیست.
ساخت `npm run build` واقعاً امتحان شد و به دلیل نبود Cargo پیش از کامپایل Tauri متوقف شد. محیط اجرا Linux است، نه Windows/WebView2.
بنابراین ساخت بومی ویندوز، اتصال واقعی VPN و انطباق پیکسلی ۱۰۰٪ در WebView2 تأیید نشده‌اند. تصاویر آزمون با Chromium و IPC آزمایشی ساخته شده‌اند، نه اتصال واقعی سرورها.

## مرجع و محدوده
- مبنای تغییرات: آرشیو ورودی `Aether_Windows_V1.4.0.zip`.
- مرجع بصری: ده تصویر Windows و پنج تصویر Mobile از `Pictures.zip`.
- متن راهنمای راستی‌آزمایی و ساختار OptionCard با سورس موبایل در آرشیو `Aether-1.6.0.zip` نیز تطبیق داده شد؛ هیچ کد شبکه‌ای از آن جایگزین نشد.
- نسخه برنامه **1.4.0** و هسته **2.4.0** باقی مانده‌اند. فایل‌های تنظیمات Tauri، Cargo و قفل وابستگی‌ها تغییر نکرده‌اند.
- مقایسه SHA-256 برای **۲۲۹۲ فایل** در `src-tauri`، `native` و `third_party` با ورودی اصلی: **صفر تغییر، حذف یا اضافه**.

## اصلاحات انجام‌شده
1. فلش‌های انتخابگر در RTL رو به چپ؛ جهت LTR و فلش‌های کشوییِ رو به پایین حفظ شد.
2. «کشور خروجی» اصلاح شد و راهنمای آن از ستون باریک عنوان خارج و زیر کل ردیف قرار گرفت.
3. نام‌های فنی Aether و Tor در انتخاب بک‌اند انگلیسی‌اند، بدون تغییر برند فارسی برنامه. MASQUE×2 انگلیسی و مستقل از جهت متن است.
4. سوئیچ اصلی راستی‌آزمایی از ترابرد به کارت مستقل بالای هسته منتقل شد؛ همان کلید `verifyConnection` و ذخیره‌سازی قبلی حفظ شده‌اند. راهنما دقیقاً متن موبایل است. تنظیم مستقل کانفیگ سفارشی جابه‌جا نشده است.
5. کاشی‌های پروتکل دو ستونه و جدا از هم‌اند؛ گزینه آخر تمام‌عرض، رنگ و حاشیه هر گزینه مشخص است.
6. عنوان تکراری کانفیگ‌های ذخیره‌شده حذف شد. تب‌ها کپسول مستقل و بدون پس‌زمینه/خط اضافی‌اند؛ فقط نوار تب‌ها برای دسترسی به تب‌های بیشتر افقی حرکت می‌کند و scrollbar نقاشی نمی‌شود.
7. افزودن کانفیگ و تب جدید هم‌ارتفاع و کنار هم، به‌ترتیب سبز و صورتی تیره‌اند.
8. عرض ثابت ۵۶۰ پیکسلی جدول برداشته شد. دامنه زیر برچسب‌های نوع/پینگ می‌شکند؛ نام طولانی، پورت و دکمه سه‌نقطه داخل عرض پنجره می‌مانند. جدول افقی اسکرول نمی‌شود؛ اسکرول عمودی فهرست حفظ شده است.
9. تست پینگ همه به کارت تمام‌عرض زیر جدول، همراه آیکون و راهنما و دکمه دستیار منتقل شد؛ فرمان `cc_ping_all` عوض نشده است.
10. لوگوی مثلثی از هدر کشو حذف شد. گروه‌ها و جداکننده‌های منو با فاصله و تورفتگی یکسان تنظیم شدند.
11. Link or text، Import file و Name به «لینک یا متن»، «وارد کردن فایل» و «نام» ترجمه شدند.
12. عنوان‌ها و فیلدهای فارسی راست‌چین و آیکون‌های Gemini در ردیف عنوان قرار گرفتند؛ قاعده flex عمودیِ مزاحم رفع شد. رشته‌های فنی در ورودی‌ها ترتیب LTR خود را حفظ می‌کنند.
13. رنگ Gemini از توکن `#9B8CFF` استفاده می‌کند؛ دروازه بسته دیگر آیکون راهنما را تقریباً نامرئی نمی‌کند و منطق دروازه عوض نشده است.
14. باگ کشف‌شده در تست مدال رفع شد: Escape در مرحله capture فقط مدال را می‌بندد و باعث بازگشت همزمان از زیرصفحه نمی‌شود.

## آزمون‌های اجراشده روی این اصلاحات
| آزمون | نتیجه |
| --- | --- |
| `npm ci --no-audit --no-fund` | موفق |
| `npm run web:build` | موفق؛ bundle تولیدی Vite |
| `npm test` | موفق؛ همه مجموعه‌های اصلی، نحو JS، CSS، تنظیمات، پینگ، drop فایل و QR |
| `CHROME=/path/to/chromium npm run test:layout` | موفق؛ هارنس موجود با IPC آزمایشی |
| `CHROME=/path/to/chromium npm run test:parity` | موفق؛ آزمون جدید DOM و هندسه واقعی Chromium |
| مقایسه هش فایل‌های محافظت‌شده | ۲۲۹۲ فایل برابر با ورودی |
| `npm run build` | متوقف؛ Cargo نصب نیست؛ EXE ساخته نشد |

آزمون parity چهار حالت دارد: فارسی 390×820، فارسی 360×720، فارسی 760×900 و انگلیسی 390×820. صفحات اتصال، شیت بک‌اند، جایگاه/ذخیره سوئیچ، نبود آن در ترابرد، DNS، برنامه‌ها، محافظت نشتی، Zero Trust، جدول با ۱۲ رکورد و نام/دامنه طولانی، پینگ، مدال‌ها و کشو بررسی می‌شوند. خوانایی برچسب پینگ و محصور بودن منوی سه‌نقطه نیز سنجیده می‌شود.
تصاویر فارسی در دو عرض ۳۹۰ و ۳۶۰ در `validation/ui-parity/screenshots` قرار دارند. بازبینی بصری صفحات اصلی در عرض ۳۹۰ و حالت‌های حساسِ عرض ۳۶۰ انجام شد. این بررسی معادل اندازه‌گیری تطابق پیکسلی تصاویر Android نیست.

## فایل‌های اصلی اصلاح‌شده
- `src/views/advanced.js`: کارت اتصال، راستی‌آزمایی و انتخابگرها.
- `src/views/customconfigs.js`: جدول، تب‌ها و کارت تست پینگ.
- `src/views/settings.js`: نام‌های فنی و تزریق سرعنوان دستیار.
- `src/styles/parity.css`: قواعد اصلاحیِ نهایی و محدود به رابط.
- `src/i18n.js` و `src/index.html`: ترجمه‌ها، حذف لوگو و بارگذاری CSS.
- `src/ui/modal.js`: جلوگیری از عبور Escape به صفحه زیرین.
- `tests/visual-parity.mjs`: هارنس مستقل جدید؛ mock فقط در تست وجود دارد.
- تست‌های CSS، file-drop و settings با حذف عنوان زائد و کارت اطلاعاتی مستقل هماهنگ شده‌اند؛ مجموعه تست‌ها حذف یا غیرفعال نشده‌اند.
- `package.json`: فقط فرمان `test:parity` افزوده شده؛ نسخه و وابستگی‌ها تغییر نکرده‌اند.

## بازتولید و ساخت ویندوز
```sh
npm ci
npm test
npm run web:build
# برای آزمون مرورگر، CHROME را مسیر Chromium/Chrome نصب‌شده قرار دهید:
CHROME=/path/to/chromium npm run test:parity
```
برای بیلد بومی از محیط Windows و پیش‌نیازهای موجود پروژه یا workflow فعلی `.github/workflows/build.yml` استفاده شود. `core_sync=off` باقی بماند. این جلسه تغییری در workflow، منابع موتور، src-tauri، شبکه، سوکت یا Rust ایجاد نکرده است و هیچ انتشار یا push انجام نشده است.

## گزارش‌ها و سلامت بسته
گزارش‌های این نوبت فقط در `validation/ui-parity` هستند. سایر گزارش‌های قدیمی پروژه مربوط به ورودی‌اند و شاهد اجرای آزمون Rust/Windows در این نوبت نیستند.
`SOURCE_MANIFEST.sha256` برای محتویات تحویلی (به‌جز خود مانیفست) بازتولید شده است. `node_modules`، فایل‌های موقت و cacheها در ZIP نیستند.
